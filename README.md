## 🌟 Overview & Philosophy

This repository serves as the **official architecture showcase and design case study** for my personal portfolio. 

The portfolio was engineered from the ground up without heavy CSS utility frameworks, prioritizing raw performance, custom shader aesthetics, and sensory micro-interactions. It features a bespoke Apple-inspired **Liquid Glass & Dark Optical** design system powered by real-time WebGL/Three.js rendering.

---

## ✨ Key Technical Highlights

- **Dynamic 3D Canvas Optics**: Custom real-time Three.js scene with chromatic lighting and reactive particle dynamics.
- **Physics-Based Kinetic Motion**: Orchestrated with **GSAP (GreenSock)** and **ScrollTrigger** for natural fluid momentum across scroll states.
- **Inertial Smooth Scrolling**: Powered by **Lenis** to decouple hardware wheel jitter and deliver consistent 60fps pacing.
- **Mouse-Reactive Illuminations**: Real-time CSS custom property (`--mouse-x`, `--mouse-y`) radial spotlights across buttons and interactive cards.
- **Split Typography Animations**: Text reveals driven by **Split-Type** for staggered cinematic line entrances.
- **Custom Interactive Preloader & Cursor**: Seamless initial page load sequence with responsive custom cursor states.
- **Full-Spectrum Responsiveness**: Handcrafted media queries providing an equally immersive experience on mobile, tablet, and ultra-wide screens.
